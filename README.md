# 📓 Notebook Project

The **Notebook Project** is a simple web application that allows users to create, view, edit, and delete notes. It provides a convenient way to organize and manage your notes online.

![Notebook Preview](notebook-preview.png)

## ✨ Features

* **Create Notes:** Create new notes by providing a title and content.
* **View Notes:** View all notes in an organized list.
* **Edit Notes:** Edit the title and content of existing notes.
* **Delete Notes:** Delete notes when they are no longer needed.
* **Responsive Design:** Works well on desktop and mobile devices.

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/MALB1993/NoteBook.git
cd NoteBook
```

### 🌐 Run with Live Server

This project requires a **Live Server** to run correctly.

You can use the **Live Server extension in Visual Studio Code**.

#### Using VS Code Live Server

1. Open the project folder in **Visual Studio Code**.
2. Install the **Live Server** extension.
3. Open the `index.html` file.
4. Right-click on `index.html`.
5. Select **Open with Live Server**.
6. The project will open automatically in your browser.

> ⚠️ **Important:** Opening `index.html` directly in the browser may not work correctly. Please use a Live Server.

## 📝 Usage

### Create a Note

1. Click on the **New Note** button.
2. Enter a title and content for your note.
3. Click **Save** to create the note.

### View Notes

1. Open the application.
2. All notes will be displayed in a list on the homepage.
3. Click on a note to view its details.

### Edit a Note

1. Click on the note you want to edit.
2. Click the **Edit** button.
3. Update the title or content.
4. Click **Save** to save the changes.

### Delete a Note

1. Click on the note you want to delete.
2. Click the **Delete** button.
3. Confirm the deletion.
